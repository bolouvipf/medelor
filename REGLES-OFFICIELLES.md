# RÈGLES OFFICIELLES — Meta Global AI Developer Hackathon
Source : Participant Guide (Cerebral Valley), copié par le porteur le 27 oct 2026.
En cas de doute, le guide d'origine et le Discord (#questions) font foi, pas ce résumé.

## Objectif
Le projet doit répondre à l'un des deux énoncés :
- **Build for Your World** : résoudre un problème qu'on connaît de première main.
- **Push the Frontier** : défis logiciels, robotique, énergie, matériaux, systèmes physiques.

Le projet doit **incorporer les modèles Meta** :
- via Meta Model API : série Muse Spark, Muse Wonder, Muse Image, Muse Voice Transcribe, SAM 3.1 ;
- en poids ouverts : Muse Glimmer, Muse Spark Open ;
- Muse Code (agent de code) pour développer plus vite.

## Règles
- Dépôt public.
- Équipe de 4 au maximum, solo autorisé.
- Seul ce qui est construit pendant l'événement compte. La démo ne montre que ce qui a été construit. Une identification floue des contributions = disqualification immédiate.
- Les startups peuvent s'appuyer sur un existant, à condition d'identifier clairement le nouveau travail.
- Disqualification : violation de règles légales/éthiques/plateformes, ou usage de code, données ou assets sans les droits.
- Projets génériques déconseillés : conseil médical par IA, RAG basique, analyseur d'images simple, chatbot éducatif simple, tri de candidatures, coach nutrition, analyseur de personnalité, analyseur sportif, tout sujet politique ou de guerre.

## Soumission
- Date limite : **mercredi 4 novembre, 21h (ET)**. Les soumissions tardives ne sont pas examinées.
- Équivalent Cotonou : jeudi 5 novembre, 3h du matin.
- **Limite interne : mercredi 4 novembre, 18h (Cotonou).**

- Vérifier : dépôt accessible publiquement, lien vidéo accessible, tous les contributeurs listés.
- Vidéo de **3 minutes** : fonctions, code et fonctionnalités construits pendant l'événement.

## Jugement
- **Étape 1 (réussite/échec)** : le projet cadre avec le thème et utilise réellement l'API Meta et/ou les modèles ouverts.
- **Étape 2 (notes de 0 à 10)** :

| Critère | Poids |
|---|---|
| Impact | 30 % |
| Utilisation des outils Meta | 25 % |
| Profondeur technique et exécution | 20 % |
| Démo | 25 % |

- **Étape 3** : les 5 meilleurs de chaque piste, jugés en direct sur la vidéo.
